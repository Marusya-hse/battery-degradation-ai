**Контекст.** Срок службы аккумулятора зависит от режимов заряда, температуры и химии ячейки, а деградация нелинейна и плохо описывается простыми формулами. Модели, обученные на циклических данных, позволяют предсказывать состояние здоровья (SOH) и оставшийся ресурс задолго до отказа. Это важно для электротранспорта и систем накопления энергии.

## Цель и задачи

**Цель:** создать модели раннего прогноза деградации аккумуляторов с оценкой неопределённости и исследовать перенос между химиями ячеек.

**Возможные задачи** _(команда с куратором выберет приоритетные):_

- [ ] Подготовка данных циклирования: признаки из кривых заряда и разряда (IC/DV-анализ, внутреннее сопротивление).
- [ ] ML-этап: предсказание SOH и числа оставшихся циклов; ранний прогноз по первым десяткам циклов.
- [ ] DL-этап: последовательные модели (LSTM, TCN, трансформеры) на сырых кривых вместо ручных признаков.
- [ ] Суррогатные модели, сочетающие физику (эквивалентные схемы, полуэмпирические модели деградации) и данные.
- [ ] Обнаружение аномалий: выявление ячеек с аномальной динамикой деградации до отказа.
- [ ] Кросс-доменное обучение: перенос на новую химию ячеек и новые протоколы циклирования при малом объёме данных.
- [ ] Сервис: API оценки состояния батареи по загруженным циклам и дашборд мониторинга парка ячеек.
